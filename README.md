# Project 3: Capturing & Analyzing Live Stock Data

## Overview

This project explores methods for capturing live stock market data and applying statistical techniques to analyze it. The focus is on understanding stock behavior through descriptive statistics and potentially informing trading decisions using prescriptive insights.

*(Note: The specific methods for capturing live data are not detailed in the provided asset link but are the conceptual focus).*

## Skills Demonstrated

* **Descriptive Statistics:** Calculating and interpreting measures like mean, median, standard deviation, and variance to summarize stock price movements.
* **Prescriptive Statistics:** Utilizing statistical insights to potentially recommend actions or strategies (e.g., identifying potential buy/sell signals based on historical volatility or trends).
* **Data Interpretation:** Drawing meaningful conclusions from statistical analysis of financial data.
* **Conceptual Understanding:** Demonstrating knowledge of stock market data characteristics and analytical approaches.

## Tools Used

* **Statistical Software/Libraries (Conceptual):** Tools like Python (with libraries like Pandas, NumPy, SciPy) or R would typically be used for such analysis.
* **Microsoft PowerPoint:** For presenting the statistical concepts and analysis framework.
